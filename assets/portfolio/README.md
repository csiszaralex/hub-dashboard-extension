# Portfolio images

Full-size (2560×1600) copies of the store screenshots, plus an architecture
diagram. The English captions of the screenshots are in the store listing's
screenshot table (`apps/extension/store-listing.md`, "Screenshots"); the
Hungarian ones are below.

| File                  | Felirat                                                                                              |
| --------------------- | ---------------------------------------------------------------------------------------------------- |
| `1-overview.jpg`      | Minden egy pillantásra: a következő meeting, az időjárás, egy visszaszámláló és a napi idézet egy friss fotó fölött. |
| `2-memos.jpg`         | A saját jegyzeteid a saját szerveredről: címke szerint böngészhetők, és új memó is írható az új lapon. |
| `3-focus.jpg`         | Egy fókusz időzítő minden fülre: a háttérben fut, és egyszer szól, akkor is, ha egy fül sincs nyitva. |
| `4-minimal.jpg`       | Rejts el bármit. Ha minden widget ki van kapcsolva, a Hub csak az idő és egy fotó.                    |
| `5-architecture.svg`  | Adatvédelem a felépítésben: a kulcsok a Workerben maradnak, a jegyzetek, a naptár és a hely sosem mennek át rajta. |
